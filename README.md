# Software Testing Experiment 03

## 实验目的

1. 巩固基于控制流白盒测试知识，对于给定的待测程序，能熟练应用基本控制流覆盖方法设计测试用例；
2. 通过绘制程序控制流程图，实现对程序源代码的逻辑描述；
3. 培养严谨和系统的测试精神，学习测试用例的设计和分析。

## 实验步骤

1. 画出Demo.java的程序流程图
2. 用语句覆盖和判定覆盖方法设计测试用例
3. 使用条件覆盖、判定条件覆盖和条件组合覆盖方法设计测试用例集
4. 基于JUnit实现上述5组测试用例集，要求在每个测试用例集上实现100%覆盖率
5. 完成测试报告

## 注意事项
1. 程序流程图只有 1 个入口，1 个出口；
2. 根据使用的测试方法，把判定和条件在测试用例执行时的取值给出来；
3. 没有执行的判定和条件没有取值；
4. 条件组合测试时，对一个判定中的条件取值进行组合；
